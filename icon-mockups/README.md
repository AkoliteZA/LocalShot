# LocalShot Icon Mockups

Five non-destructive icon directions for replacing the current Snapzy-like app icon.

| Option | Direction | Palette | Best fit |
| --- | --- | --- | --- |
| 01 Focus Frame | Capture target, region frame, precision dot | `#062B2F`, `#21CFA6`, `#F8FAF7` | Strong all-rounder for a screenshot utility |
| 02 Local Lens | Screenshot card, OCR/search lens, warm identity | `#E5484D`, `#FFF7EA`, `#254559` | Friendlier, more consumer-facing app feel |
| 03 Privacy Shutter | Shield, capture corners, local-first signal | `#111820`, `#8BE66E`, `#F4F7F2` | Privacy-focused positioning |
| 04 Annotate Burst | Screenshot card plus pencil/markup energy | `#241B38`, `#F6D65A`, `#FF6F91` | Capture-and-edit workflow emphasis |
| 05 History Stack | Stacked captures, save/download gesture | `#173142`, `#2AA59F`, `#F3C969` | Local history and repeat capture emphasis |

Files:

- `localshot-icon-options.svg`: editable vector contact sheet.
- `localshot-icon-options.svg.png`: rendered PNG preview.
- `localshot-focus-history-selected.svg`: selected Focus Frame icon using the History Stack colour scheme.
- `localshot-focus-history-selected.svg.png`: selected `1024x1024` PNG source used for the app icon catalog.

The production `AppIcon.appiconset` has been replaced with the selected Focus Frame + History Stack palette.
